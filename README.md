# ✨ Features

## 📚 Smart Course System
- Interactive learning courses
- Organized lessons and educational content
- Detailed course viewer
- Structured learning experience

## 🧠 Quiz & Assessment Module
- Dynamic quizzes
- Score calculation
- Quiz history tracking
- Result visualization
- Performance analytics

## 🏆 Achievement & Badge System
- Unlockable badges
- Motivation-based learning
- Progress rewards system

## 📈 Progress Tracking
- User progression dashboard
- Learning statistics
- Performance monitoring
- Personalized experience

- Login interface
- User session management
- Secure application flow

## 🎨 Modern UI/UX
- Custom Qt Stylesheets (`app.qss`)
